# 自动化测试数据集

> 每组测试用例 = 一组素材 + 若干轮用户自然语言输入。用于自动化验证服务能否跑通及各轮耗时。
>
> **素材仓**：每组素材归档在 `tests/dataset_materials/用例组N/`（已 gitignore，不入库）。
> 跑某组之前先装填素材：`python tests/load_dataset.py 用例组N --clean`
> （`--clean` 清空 INPUT/ 后装入该组全部素材，复刻原始运行环境；不加则增量装填，残留文件会扰动素材编号）
