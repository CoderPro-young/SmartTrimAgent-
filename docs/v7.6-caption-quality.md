# V7.6 文案质量升级：desc 画面描述 + prompt 重写 + 数量重试

> 2026-09-30。V7.2 解决了「文案与画面对不上」（选材后写、逐段绑定），
> 本轮解决「文案本身不好」：输入太糙（标签词）、prompt 没有质量约束、
> 一次失败就作废。三条对应三个改动点。

## ① 打标加 desc（content_analysis）——输入从标签词升级为具体画面

`_TAG_PROMPT` 新增 **desc：一句话画面描述（30~40 字）**——主体在做什么、
景物有什么，写具体的名词、动作与光线，**不要评价词不要抒情**
（示例：「穿红裙的女孩背对镜头走向金色草地，风把裙摆吹起」）。

- 文案模型 `_write_captions` 的镜头清单优先用 desc（「一句具体画面」），
  旧卡无 desc 时退回标签清单——**老缓存卡片无需重建即可受益于新卡**。
- `shot_select` 的 `text_any` 跨字段 OR 匹配同步纳入 desc：关键词能命中
  画面描述（「红裙」不再是 tags 里没有就筛不到）。
- 卡片体积增量可控（每镜头一句），sidecar 缓存结构不变。

## ② prompt 重写（workflow._CAPTION_PROMPT）

- **few-shot 示例**：3 个镜头的输入 → 输出（输入正是 desc 体例，教模型
  「从具体画面到口语短句」的映射）；
- **禁用词清单**：治愈、宁静、岁月静好、定格、美好时光、难忘、风景如画、
  心旷神怡、流连忘返、逃离城市——实测最容易流出的 AI 味套话，直接点名禁用；
- **叙事结构**：第 1 句是钩子（提问/断言/悬念），最后 1 句收束（感受或
  呼应主题），中间句以画面为主体自然衔接；
- 细则：每句 ≤14 字、不复述标签词（「空镜」「无」）、keyword 尽量在
  首句或末句体现。

## ③ 解析失败/句数不齐带反馈重试一次

此前 JSON 解析失败或句数对不上**直接作废退 labels 兜底**；现在把失败
原因（「解析失败」/「只有 N 句」）拼进 `_RETRY_NOTE` 回喂一次——
句数不齐是高频失败（模型自由发挥多写/少写一句），带反馈重试的命中率
远高于从头再来。两次都不行才作废。

## ④ 字幕避开水印（y_margin / bottom_margin_ratio）

相机自带水印（影石/DJI 常驻画面底部）会被贴底字幕压住。底部字幕的
贴边留白改为**按画布高度比例**换算（`bottom_margin_ratio: 0.12`），
编译器注入 `y_margin`（像素，随预览缩放比同步缩放）；固定像素边距在
高分辨率下只占高度几个百分点，压不住水印，比例法与分辨率无关。
手写计划也可显式给 `y_margin`（schema 白名单已收）。

## 前端配套

`labels` 兜底文案在前端审阅摘要**显式标注来源**——「标签拼接」出来的
句子与 LLM 现写的句子观感差距明显，用户应当知道拿到的是哪一档。

## 测试

`tests/test_v76_caption_quality.py`（9 项，离线）：desc 输入优先与旧卡
回退、禁用词/钩子-收束进 prompt、重试一次的命中与两次失败作废、
text_any 命中 desc、y_margin 换算与注入、report 来源标注。
