# V6.0 —— 粗剪减法漏斗

> 2026-09-27。产品定位收敛为「减法漏斗」后的第一期落地：**粗筛（扔垃圾）→ 去废（已有）→ 三形态交付**。
>
> 决策记录（用户拍板）：交付物三形态全做（成片 + 时间线导出 + 筛选报告）；
> 废料移除走「报告 + 一键应用」（区别于出片的「直接出片」——破坏性操作给用户拍板权）；
> 先做无 ASR 的粗剪闭环，ASR 下期加深去废层。

## 0. 定位框架

粗剪用户带着几十上百条未整理素材进来，要的不是惊艳成片，而是**快速把体量减下来**：

```
一堆素材 ─→ ①粗筛（扔垃圾）─→ ②去废（剪废段，V5 已有 cut_silence/cut_black）
        ─→ ③交付（成片 / 时间线 / 报告）
```

调研验证（auto-editor / FireRed / OpenMontage）：漏斗每层都有人单独做成产品，
没人做全——三层贯通是空位，而「信号 + select 宏 + 计划编译」架构天然贯通。

## 1. 粗筛层：`video_editing/culling.py` + 两个端点

- 纯规则废料判定（零幻觉，只判断事实可用性不判断内容好坏）：
  全静音（静音占比 ≥99%，Pexels 环境音轨实测 100%）、全黑场（≥95% 覆盖）、
  画质全差（所有镜头 quality=poor）、过短（<2s）；未索引不判定（信息不足宁可放过）。
- `GET /api/cull-report`：废料清单（带中文原因）+ 统计；**只建议不动手**。
- `POST /api/cull-apply {names}`：用户勾选后一键移除（真删失败降级 TMP/removed/，
  白名单同步清理，任务运行中拒绝）。
- 前端：素材库新增「粗筛 · 废料检查」卡（缩略图 + 原因 + 勾选 + 一键应用）。

## 2. 交付层：`video_editing/timeline_export.py`

- **EDL（CMX3600）**：计划+数学 → 业界通用交换格式，剪映专业版 / Premiere /
  Resolve / FCP 均可导入继续精剪；转场以注释行标注（粗剪语义按硬切导入）。
  行格式参考 auto-editor：`001  AX V C  源入 源出 录入 录出`。
- **CSV 剪辑表**：源入出点 / 时长 / 时间线位置 / 转场 / 效果，UTF-8 BOM 防 Excel 乱码。
- 时机：`/api/run` 与 `/api/replan` 的 done 阶段自动落 `OUTPUT/<成片名>.edl/.csv`，
  done 事件带 `exports` 下载链接；导出失败不影响成片交付。
- `/api/outputs` 一并列出 .edl/.csv。

## 3. 筛选报告：select 宏返回 rejected

- `shot_select.collect_candidates` 现在返回 (candidates, rejected)，每个被拒镜头带
  中文原因（场景不匹配 / 人数 / 画质 / 时长 / 静音占比 / 装不进预算）。
- 编译器 select 报告带 `rejected`（前 50 条）+ `rejected_total`；前端审阅报告渲染
  「未入选 N 个镜头 + 原因分布」——粗剪的透明性：没进片的镜头去哪了，一目了然。

## 4. 配套优化

- 提示词：select 前不再逐个 `analyze_media` 拉全卡（上传即索引已保证卡片就绪，
  拉全卡浪费上下文）；仅在编译器报缺卡时补 analyze。
- 后台索引并发 2 路（Semaphore(2)），多素材建卡提速。
- 任务模板新增「🗂 先粗剪一轮」置顶入口。

## 5. 验证

- 离线单测 `tests/test_v6_roughcut_loop.py` 14 项（判定规则边界 / EDL 时间码与
  转场归属 / CSV 格式 / rejected 原因与预算）+ V5/V4 回归 45 项全过。
- 端到端（真实素材）：粗筛报告精确命中 2 个全静音 Pexels 素材（即 V5 实测中
  触发"整条无声"路径的那两个）；replan 出片后 EDL/CSV 落盘，时间码核对无误
  （6.5s 起点 = 00:00:06:15 @30fps），done 事件带导出链接。
