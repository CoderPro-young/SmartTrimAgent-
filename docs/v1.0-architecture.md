# 视频处理与剪辑 Agent —— 技术方案 v1.0

- 版本：v1.0（2026-08-21）
- 状态：可运行验证版（LLM 生成 ffmpeg 命令 + 工具执行，ffmpeg 未预装时命令仍可见）

## 1. 背景与目标

用户希望构建一个**视频处理与剪辑 Agent**：用户用自然语言描述需求（转码、拼接、剪辑、滤镜等），
Agent 自动完成素材处理。

长期目标（能力栈）：
- 转码：分辨率、封装格式、编码格式
- 多素材：拼接、剪辑（截取/分割）、滤镜处理
- 后续可扩展：抽帧、字幕、音频处理、模板化工作流

**v1.0 范围（本文档）**：最小闭环 ——
1. LLM 根据自然语言生成 **ffmpeg 命令行**
2. 通过 `run_ffmpeg` 工具执行该命令
3. 本机未装 ffmpeg 时，命令仍完整输出，供人工/后续验证

## 2. 架构设计

```
用户自然语言
   │
   ▼
┌─────────────────────────────────────────────┐
│  deepagents (create_deep_agent)             │
│  ├─ LLM: deepseek-ai/DeepSeek-V4-Flash      │
│  ├─ System Prompt: ffmpeg 命令生成规则      │
│  ├─ Tool: run_ffmpeg(command) → subprocess  │
│  ├─ Tool: ls/glob/read_file（内置）         │
│  └─ Backend: LocalShellBackend(root_dir=./) │
└─────────────────────────────────────────────┘
   │
   ▼
INPUT/sample.mp4 ──► ffmpeg ──► OUTPUT/*.mp4/avi/...
```

- **模型**：`deepseek-ai/DeepSeek-V4-Flash`（SiliconFlow，OpenAI 兼容，工具调用稳定、成本低）
- **Agent 框架**：deepagents 0.7.7（本机已装），自带 filesystem 工具 + 可注册自定义工具
- **命令执行**：`run_ffmpeg(command)` 接收完整命令行，shlex 拆分后 subprocess 执行，
  超时 600s；ffmpeg 不在 PATH 时返回可读错误（保留命令原文）
- **目录约定**：`INPUT/`（素材）、`OUTPUT/`（产物）、`docs/`（本方案，按版本迭代）

## 3. 关键实现

文件：

| 文件 | 职责 |
|---|---|
| `video_agent.py` | 构建视频 Agent：system prompt、`run_ffmpeg` 工具、输入/输出目录 |
| `video_demo.py` | 演示入口：打印 LLM 生成的 ffmpeg 命令与最终答复 |
| `model.py` | 模型解析（默认 `deepseek-ai/DeepSeek-V4-Flash`，可用 `MODEL_NAME` 切换） |
| `INPUT/` | 测试素材（`sample.mp4`） |
| `OUTPUT/` | 处理产物（自动创建） |

### run_ffmpeg 工具设计

```python
@tool
def run_ffmpeg(command: str) -> str:
    """执行完整 ffmpeg 命令行，返回 stdout/stderr/退出码"""
```

- 仅接受以 `ffmpeg` 开头的命令，禁止 shell 链式（`&&`、管道）
- `cwd=PROJECT_ROOT`，保证 `INPUT/`、`OUTPUT/` 相对路径生效
- ffmpeg 未安装 → 返回错误信息 + **完整命令原文**（可读、可复制）

### System Prompt 要点

- 输入在 `INPUT/`，输出必须写 `OUTPUT/`，禁止覆盖输入
- 规划前先 `ls`/`glob` 确认素材文件名
- 命令生成规范：remux 用 `-c copy`、转码用 `-c:v libx264`、分辨率用 `-vf scale=` 等
- ffmpeg 缺失时仍给出命令并说明安装方式

## 4. 验证结果（v1.0）

任务：`把 INPUT/sample.mp4 转成 AVI 封装格式（编码不变），输出到 OUTPUT/`

- LLM 生成：`ffmpeg -i INPUT/sample.mp4 -c copy OUTPUT/sample.avi` ✅ 命令正确
- 工具执行：ffmpeg 未安装 → 返回可读错误（含命令原文） ✅ 符合预期
- Agent 答复：给出命令 + 安装指引 ✅

## 5. 已知限制

1. **ffmpeg 未预装**：命令生成已验证，真实转码需安装 ffmpeg（`winget install ffmpeg`）后启用
2. **无媒体探测**：V1 不探测素材真实分辨率/编码，LLM 依赖文件名推断；无法预校验命令参数是否与素材匹配
3. **命令无校验**：LLM 生成的命令直接执行，缺少安全白名单/参数校验（转码参数错误可能产生无效文件）
4. **多素材工作流**：拼接/剪辑需要 ffprobe 获取时长、关键帧等信息，V1 未覆盖

## 7. 如何运行（v1.0）

```bash
cd deepagent-demo
export SILICONFLOW_API_KEY="sk-..."
export MODEL_NAME=deepseek-ai/DeepSeek-V4-Flash
python video_demo.py                          # 默认任务：转 AVI 封装
python video_demo.py "把 sample.mp4 转成 720p" # 自定义自然语言指令
```

安装 ffmpeg 后（Windows：`winget install ffmpeg`），`run_ffmpeg` 将真实执行，
产物写入 `OUTPUT/`。
