## V8.1 创作流 skill 注册表（creative_skills.py）

V8.0 的 Creative workflow 是写死在 `V2_SYSTEM_PROMPT_TEMPLATE` 里的一段字符串。
V8.1 起抽成 `creative_skills.py` 注册表——与 skills.py（效果）/ workflow.py（宏）
同构的「一处定义 → 提示词派生」，`video_agent` 用 `{CREATIVE_DOC}` 占位符装配
（顺手修复了 V8.0 插入时产生的重复小节标题）。

- **结构**：`CreativeSkill(name, summary, flavor)`——summary 是路由条件（进
  skill 菜单），flavor 是该 skill 的节奏/文案指导；七步主流程与筛选/分组硬规则
  是全部 skill 共享的 `COMMON_STEPS`。**新 skill = 加一个注册项，不改公共段。**
- **首批三个**：`general_vlog`（兜底）、`travel_vlog`（沿行程弧线组叙事、
  Hook 用最壮观的 2-4s、结尾"还想再来"不升华）、`food_vlog`（围绕"做"的过程
  组叙事、Hook 用最有食欲的动作镜头、动词与感官名词）。
- **与 FireRed 的机制差异**（记录）：它是 SKILL.md 文件按需加载 + agent 显式
  选择；我们是注册表整段常驻提示词——零路由失败、零加载机制，代价是常驻
  ~1k token；skill 数量显著变多时再考虑按需注入。

## V8.2 BGM 节拍卡点（beat_detect + audio.snap_beats）

FireRed `plan_timeline` 的 `use_beats`：把镜头切换点吸附到音乐节拍（beats 对齐
是它成片"有节奏感"的主要来源之一）。本项目的对应实现：

### 信号：`beat_detect.detect_beats(src, root)`（零新依赖）

ffmpeg 解码单声道 f32 PCM @22050（`ffmpeg_exec.run_binary` 管道，可被取消）→
分帧能量 → onset 包络（能量正差分）→ 自相关定 BPM，两处关键修正：

- **倍频修正**：自相关常在周期 2 倍处更高（隔拍对齐无泄漏，实测 120BPM 轨在
  60BPM 拉格处 0.952 > 基频处 0.884）——取「达到峰值 85% 的最小拉格」；
- **亚帧周期细化**：帧量化（43fps）在 120bpm 处就有 4.6% 周期误差，二十秒就
  漂出容差——自相关峰抛物线插值到亚帧精度。

置信度 = 节拍处 onset 强度 / 全局均值，低于 1.6（ambient 类）返回 None——
**卡点优雅缺席，绝不硬凑**。结果按文件 stat 缓存（`TMP/probe/beats_*.json`）。
真实 ffmpeg 冒烟：2Hz 脉冲轨 → 119.9 BPM，节拍 0.5s 栅格，置信度 3.26。

### 吸附：`plan_compiler._snap_to_beats`（计划 opt-in）

- **触发**：`audio.snap_beats: true`（缺省 false——叙事对齐比节奏重要的场景
  不受影响）；`_expand_plan` 里在剪除展开之后、时间轴推导之前执行；
- **剪辑点定义**：转场中点 `start[i+1] + trans[i]/2`；调整**入画片段的
  trim_end**（或图片的展示时长）把剪辑点移到最近节拍——下游时间轴数学、
  旁白字幕窗、BGM 铺轨全部自动跟随，零特判；
- **护栏**：单次位移 ≤ `BEAT_SNAP_MAX`(0.35s，env 可调)；吸附后片段 ≥0.6s；
  视频片段**延长**需 clip 带 probe 且源内有余量（无 probe 只允许缩短）；
  最后一个边界（成片结尾）不吸附；
- **报告**：`expansions["beats"] = {bpm, snapped, skipped, max_shift}`，
  审阅报告显示「🎵 节拍卡点 N 处（BPM x，最大位移 ys）」；检测失败给中文
  原因不硬凑。

## V8.3 aes_score 美学分（FireRed understand_clips 的 aes_score 对位）

- **打标**（`content_analysis._TAG_PROMPT`）：新增 `aes_score`——美学质量
  0.0~1.0 两位小数（≥0.80 构图光影出色 / 0.60~0.79 良好 / 0.40~0.59 一般 /
  <0.40 废片级），按构图/光影/主体清晰度综合评，**不是内容有趣度**；
  `sanitize_label` 收敛钳制（越界钳到 [0,1]、非数值 None）；
- **旧卡兼容**：字段缺省 None，所有消费方 `.get`——旧缓存卡不重建、不拦截；
- **消费**：`list_shots` 行内显示「美学0.82」；`select.where.aes_min` 数值
  门槛（旧卡无分视为未约束）；创作 skill 筛选规则升级为「相似镜头保留
  aes_score 高者」；
- quality 三档仍保留（语义不同：画质缺陷 vs 美学质量）。
