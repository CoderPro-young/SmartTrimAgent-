# 视频处理与剪辑 Agent —— 整体方案（v2.0）

> 简明版：只讲 workflow 与模块职责。字段级细节见
> [v2.0-multi-material-editing.md](./v2.0-multi-material-editing.md)。

## 一句话

用户用自然语言描述剪辑需求，**LLM 产出「编辑计划 JSON」，程序把计划编译成 ffmpeg
命令序列执行并回验**——LLM 负责"意图"，编译器负责"工程正确性"。

## Workflow

```
用户自然语言任务
      │
      ▼
┌─ Agent（LLM）──────────────────────────────┐
│ 1. ls / glob 列出 INPUT/ 素材             │
│ 2. probe_media 探测每个素材的真实参数      │
│ 3. submit_plan 提交「编辑计划 JSON」       │
└──────────────────┬───────────────────────┘
                   ▼
┌─ plan_compiler（编译器，纯程序）───────────┐
│ ① 校验   schema + 白名单 + 时间不越界      │
│ ② 推导   片段时长 / 起点 / xfade offset / 总时长 │
│ ③ 生成   归一化命令×N + 主命令             │
│ ④ 执行   run_ffmpeg 逐条跑（含缓存）       │
│ ⑤ 回验   ffprobe 时长/分辨率/编码          │
└──────────────────┬───────────────────────┘
                   ▼
             OUTPUT/ 产物
```

校验失败 → 携错误信息回 LLM 重新出计划（≤2 次）。

## 模块职责

| 模块 | 职责 |
|---|---|
| `video_agent.py` | 构建 Agent。V1：`run_ffmpeg` 工具（对照保留）。V2：`probe_media` + `submit_plan` 工具、计划 schema 的 system prompt、`extract_plan()` 提取计划 |
| `plan_schema.py` | 计划 JSON 的 schema 定义与校验：白名单（转场/效果/位置）、语义规则（时间不越界、引用存在、转场时长合法） |
| `plan_compiler.py` | 编译器五步：校验 → 推导换算（时间轴数学）→ 生成命令（快速/转场两条渲染路径）→ 执行 → 回验 |
| `ffmpeg_exec.py` | ffmpeg/ffprobe 执行器：可用性检测、命令执行、ffprobe 探测；未安装时返回可读错误 |
| `video_demo.py` | 演示入口：任务 → 计划展示 → 编译 → 命令展示 → 执行回验 |
| `model.py` | 模型解析（默认 `deepseek-ai/DeepSeek-V4-Flash`） |

目录：`INPUT/` 素材、`OUTPUT/` 产物、`TMP/` 归一化中间件（可缓存）、`docs/` 方案文档。

## 计划 JSON 四大块（简述）

- `output` —— 成品规格：文件名 / 分辨率 / 帧率
- `clips` —— 进时间轴的素材：来源、裁剪区间（trim）、图片展示时长、探测元数据
- `timeline` —— 播放顺序；转场挂在"当前片段与前一个之间"
- `overlays` —— 叠加层（不占时间轴）：画中画（pip）、花字（text），时间用「相对某片段偏移」

## 运行

```bash
cd deepagent-demo
export SILICONFLOW_API_KEY=sk-...
export MODEL_NAME=deepseek-ai/DeepSeek-V4-Flash
python video_demo.py                     # 默认：多素材拼接 + 转场 + 画中画 + 花字
python video_demo.py "把 sample.mp4 转成 720p 并水平镜像"
```

本机未装 ffmpeg/ffprobe：计划、换算、命令生成均可验证；真实渲染需
`winget install ffmpeg` 后重跑。

## 扩展方式（三插槽，见详细设计 §12）

新增能力不重写 schema，落入三个通用扩展点：clip `effects`（镜像/翻转/调色）、
overlay `region`（同框/水印）、timeline `layout`（左右拼接/网格）。
